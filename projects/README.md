# ML Learning Journey — Applied Machine Learning Projects

This repository documents my transition from learning machine learning fundamentals to building production-style models with structured evaluation and error analysis.

## Projects

### 1. Credit Default Prediction

* Imbalanced classification problem
* Compared Logistic Regression vs Random Forest
* Applied threshold optimization
* Performed detailed error analysis

### 2. House Price Regression

* Regression modeling with feature engineering
* Compared linear vs tree-based models
* Residual analysis and model diagnostics

### 3. Customer Churn Prediction

* End-to-end churn modeling pipeline
* Leakage detection and feature engineering
* Precision–Recall based threshold optimization
* Error analysis with failure pattern identification

## Approach

Across all projects, focus was on:

* Structured model evaluation (not just accuracy)
* Bias–variance reasoning
* Error analysis before model improvement
* Threshold tuning for real-world use cases
